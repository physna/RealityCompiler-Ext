## Support

This extension is maintained on a **best-effort basis**. There is no
service-level agreement, no guaranteed response time, and no dedicated
support staff for it:

- **Large issues and failures** — crashes, data loss, security problems, or
  a complete failure of the scan-search workflow — should be reported as
  GitHub issues on this repository and will be prioritized.
- **Minor issues, questions, and feature requests** are welcome as GitHub
  issues, but may not receive a timely response (or any response).
- **Pull requests are welcome.** A focused fix with a clear description is
  the fastest way to get a small problem resolved.

When filing an issue, include the extension version (Extension Manager or
`config/extension.toml`), your Kit/Omniverse app version, and the relevant
console output or log excerpt.

## The Hosted Physna Platform Is a Separate Service

This extension is a thin client for the **hosted Physna platform**, which
is a commercial service and is **not covered by this repository or its
license**. Access, credentials, availability, data handling, and support
for the platform itself are governed by your organization's agreement with
Physna. Platform-side problems (authentication, indexing, matching
quality, outages) should go through your Physna account contact, not this
repository's issue tracker.
